2why it hurt

⚠️ topical ≠ verifying. The evidence added noise + ate token budget, diluting the claim signal instead of grounding it.

3fairness caveat (not hidden)

This run early-stopped at epoch 12 (best @9); the baseline ran all 15, still climbing. BUT this run's val F1 had already peaked and turned down (0.3717 → 0.3611 → …), so more epochs wouldn't have rescued it. Direction is real.

4what it means (the contribution)

For RAG-style grounding, retrieval presence is not enough — retrieval quality is the lever. A big on-topic corpus that doesn't actually verify can degrade a small from-scratch classifier.
